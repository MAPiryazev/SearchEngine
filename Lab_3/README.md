# Lesson 03: Токенизация, закон Ципфа, стемминг

В этой работе реализован препроцессинг текстового корпуса для дальнейшей индексации: токенизация, подсчёт статистик и проверка закона Ципфа на распределении частот терминов. Закон Ципфа визуализируется на графике

## Корпус
Используется смешанный корпус из Wiki и StackExchange
Для токенизации берётся текстовое поле `clean_text` (подготовленный текст без разметки), после чего считаются частоты терминов и агрегаты по всему корпусу.

## Токенизация
Токенизация выполнена по набору простых и быстрых правил:
- Приведение к нижнему регистру, нормализация `ё -> е`.
- Токеном считается последовательность букв (кириллица/латиница); дефис допускается только внутри слова (например, `санкт-петербург`).
- Числа и «шумовые» символы (пунктуация, спецсимволы) выступают разделителями.
- При смене алфавита внутри слова токен разделяется (например, `frameworkи` → `framework` и `и`), чтобы не засорять словарь смешанными формами.

В ходе выполнения считаются метрики:
- Общее число токенов.
- Средняя длина токена.

## Стемминг
Добавлен опциональный стемминг (приведение словоформ к общему базовому виду) как шаг нормализации, позволяющий:
- уменьшить размер словаря (число уникальных терминов),
- повысить полноту совпадений при поиске без учёта словоформ.

Данный шаг можно включать/выключать флагом запуска и сравнивать статистики `unique_terms`/топ-термы на одном и том же корпусе.
