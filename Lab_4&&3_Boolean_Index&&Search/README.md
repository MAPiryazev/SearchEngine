# Boolean Search Engine (Labs)

Набор лабораторных работ по инфопоиску: токенизация/нормализация корпуса, построение булевого индекса (forward + inverted) и выполнение булевых запросов (CLI и простой веб-интерфейс). [file:4]

## Lab 03: Токенизация, закон Ципфа, стемминг

Реализован препроцессинг текстового корпуса для дальнейшей индексации: токенизация, подсчёт частот терминов и проверка закона Ципфа на распределении частот. [file:4] Токенизация работает по простым правилам (приведение к нижнему регистру, нормализация `ё->е`, выделение токенов из буквенных последовательностей, разбиение при смене алфавита и т.д.), а стемминг доступен как опциональный шаг нормализации, включаемый флагом запуска. [file:4]

## Lab 04: Булев индекс и поиск

Собирается forward-index (`index.fwd`) и inverted-index (`index.inv`) в бинарном формате, после чего выполняется булев поиск по запросам с `AND/OR/NOT` и скобками. [file:4] Для построения индекса используется утилита `index_builder`, которая читает документы (например, из MongoDB поле `clean_text`) и записывает индексы в каталог `--out`, а параметр `--limit-docs` позволяет индексировать только первые N документов для тестов/бенчмарков. [file:4] Для поиска используется `bool_search`/`boolsearch`, который читает `index.inv` и `index.fwd`, парсит запрос, переводит его в ОПН (RPN) и вычисляет результат над posting lists. [file:4]

## Быстрый старт

Сборка:
- `cmake -S . -B build`
- `cmake --build build`

Построение индекса:
- `./build/index_builder --out out --limit-docs 100000` [file:4]

Поиск (CLI):
- `./build/bool_search --inv out/index.inv --fwd out/index.fwd --q "python OR java" --top 20` [file:4]
- Пакетный режим: `--qfile queries.txt` [file:4]

Веб-демо (опционально):
- Есть простой веб-слой, который вызывает CLI `boolsearch` и показывает результаты постранично. [file:4]

## Структура проекта

- `src/tokenizer.cpp` — реализация токенизации/нормализации (и опциональных флагов вроде стемминга/keep-numbers/min-len). [file:4]
- `src/index_builder.cpp` — построение индекса: чтение документов, токенизация, формирование словаря термов и posting lists, запись `index.fwd` и `index.inv`. [file:4]
- `src/bool_search.cpp` + `src/query_parser.cpp` + `src/boolean_ops.cpp` — разбор запроса и выполнение булевых операций над списками docid. [file:4]
- `src/fwd_index.cpp` / `src/inv_index.cpp` — чтение forward/inverted индексов из бинарных файлов. [file:4]
- `include/index_format.hpp` — описание формата файлов индекса (магические заголовки и оффсеты секций). [file:4]
- `include/nostl/*` — собственные контейнеры и утилиты (Vec/StrView/StrPool/HashMap и т.д.), используемые вместо STL. [file:4]
- `out/` — каталог с результатами построения (`index.fwd`, `index.inv`) после запуска `index_builder`. [file:4]
- `build/` — каталог сборки CMake (в нём появляются бинарники `index_builder`, `bool_search`, `tokenizer`). [file:4]
