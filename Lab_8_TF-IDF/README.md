
## Цель работы
Целью лабораторной работы являлась реализация ранжированного поиска на основе схемы TF-IDF. Запросы без булевых операторов трактуются как нечёткие (допускается неполное соответствие документа терминам запроса), а запросы с булевыми операторами — как строгие булевы, но с ранжированием результатов по TF-IDF.

## Реализация ранжированного поиска
Добавлена утилита `rank_search8`, которая открывает индексы формата Lab6 (`index6.inv` и `index6.fwd`), разбирает запрос и выдаёт top-N документов, отсортированных по TF-IDF скору.

### Режимы обработки запроса
- Нечёткий запрос (только термины через пробелы): кандидаты собираются как объединение (OR) постингов всех термов запроса, затем документы ранжируются TF-IDF.
- Булевый запрос (есть `&&`, `||`, `!`, скобки): запрос лексится и переводится в ОПН, кандидаты вычисляются булевыми операциями AND/OR/NOT, а итоговая выдача сортируется по TF-IDF.
